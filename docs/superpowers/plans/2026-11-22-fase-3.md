# Fase 3 — Suara, Mode Eja, Terjemah Versi Awal, PWA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spell a name with finger letters → `FS:<WORD>` chips → spoken with Web Speech; app installable as a PWA, tested on the phone through a Cloudflare quick tunnel.

**Architecture:** Two pure modules in `src/lib/` (`speech.ts`, `segmenter.ts`) with unit tests; session state in a Zustand store; small React components for chips, confidence hint and caption on `TranslatePage`; `vite-plugin-pwa` for manifest + service worker; a build-preview-over-tunnel workflow for phone testing.

**Tech Stack:** React 18, TypeScript strict, Zustand, Vitest + Testing Library, Web Speech API, `vite-plugin-pwa` (new devDependency, approved), `cloudflared` (system tool, approved).

**Spec:** `docs/superpowers/specs/2026-11-22-fase-3-design.md` (and PRD F4 letters mode, F6, F7, F12).

## Global Constraints

- UI text in Indonesian; file/variable/function names and code comments in English.
- `src/lib/` modules: pure TypeScript, no React, each with a `*.test.ts` next to it.
- Touch targets ≥ 48 px (`min-h-12`), result text ≥ 24 px (`text-2xl`+), layout works at 360 px width.
- Glosses only from `src/data/vocab.json`; fingerspelled gloss format `FS:[A-Z]{1,20}` (DECISIONS #5).
- Prosody from `src/data/prosody.json`: `pitch = 1 + pitchPct/100`, `rate = 1 + ratePct/100`; Fase 3 always `emotion: 'netral'`.
- Segmenter timings: letter hold **500 ms**, word gap **1000 ms**, sentence gap **2500 ms**, threshold **0.8**, max **20** letters.
- No new npm dependency other than `vite-plugin-pwa`. No Azure TTS, face, StageBar, translator in this phase.
- After every task: `npm test` and `npm run build` pass; `npx eslint .` clean.

## Review Focus

1. No `id-ID` voice installed, or `getVoices()` still empty on first call → `speak` still speaks with the default voice, never throws (test in Task 1).
2. One noisy frame in the middle of a held letter (e.g. `R R R B R R`) → the hold restarts but no extra letter is accepted (test in Task 2).
3. Pause then resume → no stale `sentenceEnd` fires from time spent paused (test in Task 2: `reset()` then gap).
4. User deletes a chip before the sentence ends → the spoken sentence uses the remaining chips only (test in Task 4).
5. Same letter twice (`ANNA`) → second `N` only after a release (no hand or another label) (test in Task 2).

### Task 2: `segmenter.ts` — fingerspelling mode (F4 letters part)

**Files:**
- Create: `src/lib/segmenter.ts`, `src/lib/segmenter.test.ts`

**Interfaces:**
- Consumes: `hasHand(f)` from `features.ts`; a predictor shaped like `Classifier.predictLetter`.
- Produces:
  - `type LetterPredictor = (f: FeatureVector) => Prediction`
  - `type SegmenterOptions = { threshold?: number; letterHoldMs?: number; wordGapMs?: number; sentenceGapMs?: number; maxLetters?: number }` (defaults 0.8 / 500 / 1000 / 2500 / 20)
  - `type SegmenterEvents = { letter: { label: string; confidence: number; holdProgress: number }; word: { letters: string }; gloss: string; sentenceEnd: string[] }`
  - `class Segmenter { constructor(predict: LetterPredictor, opts?: SegmenterOptions); push(f: FeatureVector, t: number): void; on<K extends keyof SegmenterEvents>(event: K, cb: (p: SegmenterEvents[K]) => void): () => void; reset(): void }`
  - `fingerspellToWord(gloss: string): string` — `FS:RAKAN` → `Rakan`; other glosses → lower case, `-` → space
  - `glossesToText(glosses: string[]): string` — words joined by space, first letter capital, ends with `.`; `[]` → `''`

Rules: frames with no hand (`!hasHand(f)`) are not sent to `predict` and count as a gap. A letter is accepted when the same label with `confidence ≥ threshold` holds for `letterHoldMs`; any different label, low confidence or no-hand frame restarts the hold. The same label right after acceptance is not accepted again until a release (no-hand frame or another label). A gap of `wordGapMs` with letters buffered emits `gloss` = `'FS:' + letters` (buffer capped at `maxLetters`). A gap of `sentenceGapMs` after at least one gloss since the last sentence emits `sentenceEnd` with those glosses, once.

- [ ] **Step 1: Write failing tests** using a scripted predictor and frames every 100 ms (`withHand` = non-zero vector, `empty` = zeros):
  - `R` at 0.9 from t=0..600 → exactly one `letter` acceptance; word buffer `R` (via `word` event).
  - `R` at 0.7 for 1000 ms → nothing accepted.
  - Review Focus 2: `R R R B R R R R R R` (100 ms apart, 0.9) → one `R` only.
  - `R` 600 ms, `A` 600 ms, then 1000 ms empty → `gloss` `'FS:RA'`.
  - Review Focus 5: `N` held 1500 ms → `N` once; `N`, 200 ms empty, `N` 600 ms → buffer `NN`.
  - After `gloss`, 2500 ms empty → `sentenceEnd(['FS:RA'])` exactly once; 5000 ms empty with no gloss → no `sentenceEnd`.
  - 25 accepted letters → gloss has 20 letters.
  - Review Focus 3: hold `R` 600 ms, `reset()`, then 3000 ms empty → no `gloss`, no `sentenceEnd`.
  - `fingerspellToWord('FS:RAKAN') === 'Rakan'`; `glossesToText(['FS:RAKAN','FS:ADI']) === 'Rakan Adi.'`; `glossesToText([]) === ''`.
- [ ] **Step 2:** Run → FAIL.
- [ ] **Step 3:** Implement as a time-driven state machine (all timing from `t` arguments, no timers).
- [ ] **Step 4:** Tests PASS.
